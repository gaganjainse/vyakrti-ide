# Vyākṛti Workbench

![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge&logo=typescript)
![React](https://img.shields.io/badge/React-19-61DAFB?style=for-the-badge&logo=react)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

A browser-based IDE for Vyākṛti, an experimental Sanskrit-oriented programming language.

## Features
- Monaco-powered code editor with custom syntax highlighting
- File management (create, rename, delete .vya files)
- Compile & run code via Rust backend
- WebSocket REPL integration
- Dark/light theme
- Keyboard shortcuts
- AST, Tokens, and Bytecode viewer panels
- Diagnostics console

## Quick Start
npm install
npm run build
npm run dev
