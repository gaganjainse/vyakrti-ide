# 🧪 vyakrti-ide (Vyākṛti Workbench)

> **Browser-based IDE for Vyākṛti**, the Sanskrit-oriented programming language:
> Monaco-powered editor, compile & run via a Rust backend, and WebSocket REPL.

- **Stack:** React 19 + TypeScript + Vite + Monaco · Rust (axum) backend

---

## Quick start

```bash
npm install
npm run build
npm run dev
```

## Features

- Monaco editor with custom `.vya` syntax highlighting
- File management (create, rename, delete)
- Compile & run via the Rust backend; WebSocket REPL
- AST / Tokens / Bytecode viewer panels + diagnostics console
- Dark/light theme + keyboard shortcuts
